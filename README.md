Saudi Medal 3D Design
Project Description
This project is a 3D design of a Saudi Arabian medal inspired by the Saudi national emblem, featuring two crossed swords and a palm tree.
The medal was designed manually using Onshape as part of a 3D modeling project. The final design was exported as an STL file for 3D printing and digital use.
Design Software
Onshape
File Format
STL
Binary Encoding
Units: Millimeter (mm)
Resolution: Fine

Project Goal
The goal of this project is to create a 3D medal design using computer-aided design (CAD) software and export the final model in STL format.
